# Hardware Components

## Required Parts

- Arduino Uno or compatible board
- HC-SR04 ultrasonic distance sensor
- 7 LEDs
- 7 current-limiting resistors, typically 220Ω
- Breadboard
- Jumper wires
- USB cable for programming the Arduino

## Notes

Each LED should be connected with a resistor to protect it from drawing too much current. The HC-SR04 sensor requires a trigger pin, an echo pin, 5V, and ground.
